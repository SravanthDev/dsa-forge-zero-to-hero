Mastery gate

Do not move on because a checkbox is green. For a topic, you should be able to:

  1. Recognize the pattern on an untagged problem.
  2. Derive the approach without a solution open.
  3. Code and test it independently.
  4. Explain correctness and complexity.
  5. Solve a fresh sibling problem.
Daily protocol — follow this every time

1. Recall: before reading anything, say what you remember about this pattern. 2. Attempt: restate constraints, make examples, propose brute force, then improve. 3. Hints: use one hint at a time; after each, close it and continue. 4. Rebuild: close the editorial and code from a blank editor. 5. Explain: correctness, complexity, edge cases. 6. Transfer: solve a new problem with the same idea. 7. Schedule: revisit tomorrow, around Day 3, Day 7, Day 14 and Day 30; if recall is easy, widen the gap; if it fails, shorten it.

Worked examples are especially useful when a pattern is new; independent practice and varied problems are needed to test transfer.
